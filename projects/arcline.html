ArcLine: a medical device labeling system

A size-first labeling and packaging system for a single-use sterile surgical device, from pouch label to carton dieline. Northvale Surgical and ArcLine are fictional: this is a self-initiated concept, not client work.

Role
Concept, research, label and packaging design, design system
Type
Self-initiated concept
Tools
Illustrator, Photoshop
Deliverables
Brand guidelines · symbol set · sterile pouch spec · pouch label · carton dieline · 3D mockup
01

The challenge

Two jobs in a very small space.

Medical device labels have to let clinical staff confirm the right device in seconds, and they also have to fit every required element (UDI barcode, lot, use-by date, sterilization, symbols and manufacturer details) into a small space, for both the US and the EU.

I set out to design a complete, production-minded system for one fictional product: ArcLine, a single-use arthroscopic shaver blade in three sizes.

02

Concept: Clinical Clarity

Built around a three-second check.

The size reads first, from any side of the box, and every regulatory element has a fixed place.

Size first

The size is the largest element on every face, set in large numerals.

Color never alone

Each size has a color (teal 3.5 mm, amber 4.5 mm, violet 5.5 mm), always paired with numerals, so the label still works in grayscale and for colorblind readers.

No default blue

I avoided the usual "medical blue" and used graphite and pine green, which still read as clinical.

03

Research and requirements

A checklist before any layout.

I researched US and EU labeling requirements and the standard symbols for medical devices, then built a requirements matrix: every label element, which packaging level it belongs on, and why. That matrix became the checklist for every layout decision.

Research: FDA 21 CFR 801, EU MDR and ISO 15223-1. In a real project, Regulatory Affairs would own and confirm the final label content.

04

Design system

Colors, type and symbols that hold up at small sizes.

Palette

Graphite #1F2328, Pine #1F5E4F, Paper #FFFFFF, Slate #3B4148 and Rule #B9BEC4, plus the size colors #3A9A93, #E3A13B and #A48BCB.

Type

IBM Plex Sans Condensed for dense small print, and IBM Plex Mono for barcode text, lot numbers and dates. A label type scale with a 6.5 pt minimum.

Symbols

A consistent 16-symbol set based on the standard device symbols, drawn on one grid so they match in weight at pouch and carton sizes.

05

Sterile pouch

Planning the label around the package.

A 140 × 250 mm chevron peel pouch holds one blade. I specified where the label goes (on the paper side, clear of all seals), a label stock compatible with ethylene oxide sterilization, and how five pouches lie flat in the carton.

06

Pouch label

Every element explained in plain language.

The 120 × 80 mm label is shown at actual size, with 20 callouts explaining each element. The data block (REF, LOT, dates and UDI) works as a variable-data template, ready to rebuild in labeling software for all three sizes. All barcodes use GS1 formatting and were test-scanned.

07

Carton

Readable however it sits on the shelf.

A straight tuck end carton, 255 × 65 × 145 mm inside, with a production-ready dieline: cut and fold lines, 3 mm bleed, a safe zone and an unprinted glue flap.

The amber size band wraps all four sides at the same height, so "4.5 mm" is visible however the box sits on a shelf. The top flap artwork is rotated 180° so it reads upright when the box is closed.

08

What I'd do next

  • Validate legibility with clinical staff.
  • Run formal barcode verification.
  • Test with label printing systems.
  • Review the content with Regulatory Affairs.
